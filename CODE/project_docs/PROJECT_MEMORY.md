# Project Memory & References

Dokumen ini berfungsi sebagai tempat penyimpanan *memory* dan referensi esensial selama pengembangan project PM SaaS Prototype ini. 
Anda dapat menambahkan catatan teknis, pedoman desain, atau referensi *workflow* yang berjalan di sini.

## 1. Arsitektur Project
- **Frontend**: React (Vite), TypeScript
- **Styling**: TailwindCSS, Class Variance Authority (CVA), clsx, tailwind-merge
- **UI Components**: Radix UI (shadcn/ui style components), `lucide-react` untuk ikon
- **State/Routing**: React Router
- **Data Visualization**: Recharts
- **Drag & Drop**: `@hello-pangea/dnd`

## 2. Struktur Folder Utama
- `src/app/` : Source code utama aplikasi (pages, components, routes, dll).
- `src/lib/` : Utility functions, konfigurasi library.
- `src/styles/` : Konfigurasi global styling (CSS).

## 3. Pedoman Desain (Design Guidelines)
- Menggunakan standar modern web design.
- Implementasi fungsional *drag and drop* pada komponen task management.
- Mengedepankan hierarki visual dan warna (Tailwind).
